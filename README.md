# 🍕 Papa Johns Web Master

A simple web application inspired by Papa Johns, built with React and Firebase. The project focuses on user authentication, menu browsing, and smooth navigation between pages.

---

## 🚀 Live Demo
https://papa-johns-web-master.vercel.app/

## 📂 Repository
https://github.com/Youssefkhalil10/Papa-Johns-web-master

---

## 🚀 Features

- 🍕 Display a dynamic menu of food items
- 🔐 User authentication (Login / Sign up)
- 👤 Dedicated login page for new users
- ⚡ Auto-login for returning users
- 🧭 Smooth navigation between pages
- 📋 Simple menu system for browsing items
- 📱 Responsive design for different devices

---

## 🛠️ Tech Stack

- ⚛️ React
- 🔥 Firebase (Authentication)
- 🌐 React Router
- 🎨 CSS

---

## 📌 Pages

- Login Page (User authentication)
- Home Page (Menu display)
- Navigation between pages using the menu system

---

## 💡 Project Overview

This project is a simplified web experience inspired by Papa Johns, focusing on authentication flow, page navigation, and displaying a structured menu using React and Firebase.
